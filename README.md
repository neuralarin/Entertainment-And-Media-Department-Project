# 🎬 CineVision   
  
-----

## 🙂 Overview  

This project focuses on building a movie recommendation system using Natural Language Processing (NLP) and machine learning techniques. By analyzing movie descriptions, genres, and other metadata, I developed a content-based recommendation system that suggests movies similar to a user's selected title.

*The goal is to improve content discovery, reduce search time, personalize recommendations based on movie similarities, and enhance the overall user experience.*
  
-----

## 💡 Problem Statement & Business Impact

* Users often struggle to discover movies that match their interests because of the large volume of available movies and shows.
* Traditional keyword-based searches may fail to identify content with similar themes, genres, storylines, and descriptions.
* Movie recommendations can be generated by analyzing textual descriptions, genres, and metadata to identify similarities between titles.
* **Goal:** Develop a content-based movie recommendation system using TF-IDF vectorization and Cosine Similarity to analyze movie information and recommend similar titles.
* **Business value:** Relevant recommendations help users discover content more efficiently, increase user engagement, improve content accessibility, and provide a foundation for scalable recommendation services.

-----

## 📊 Dataset Overview

The project uses a movie metadata dataset containing titles, genres, overviews, ratings, popularity, production details, and release information.

### 📌 Key Features Used

- `title`
- `genres`
- `overview`
- `tagline`
- `vote_average`
- `popularity`

### 🎯 Goal

Recommend movies that are **semantically similar** to the movie selected by the user.

## 🔄 Workflow

### 1️⃣ Data Cleaning & Feature Selection

- Removed duplicate records
- Handled missing values
- Selected relevant textual features

### 2️⃣ Text Preprocessing

- Combined important text fields
- Converted text to lowercase
- Removed noise and unnecessary characters

### 3️⃣ TF-IDF Vectorization

- Converted movie descriptions into numerical vectors
- Captured the importance of words across the dataset

### 4️⃣ Similarity Computation

- Calculated **Cosine Similarity** between TF-IDF vectors
- Identified semantically similar movies

### 5️⃣ Recommendation Engine

- Retrieved the **top-N most similar movies**
- Returned personalized recommendations

### 6️⃣ Backend API

- Built a **FastAPI REST API**
- Served recommendations efficiently

### 7️⃣ Frontend Integration

- Connected React frontend with FastAPI backend
- Displayed movie posters and metadata using the **OMDb API**

## 🚀 How to Run Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/virtual-arin/CineVision
cd CineVision
```

### 2️⃣ Setup Backend

```bash
cd server
pip install -r requirements.txt
uvicorn main:app --reload
```

Backend will run on:

```text
http://127.0.0.1:8000
```

### 3️⃣ Setup Frontend

```bash
cd client
npm install
npm run dev
```

Frontend will run on:

```text
http://localhost:5173
```
